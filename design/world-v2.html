Interaction spec (play world)

Semua animasi pakai Reanimated worklet — jalan di UI thread, tidak ada re-render JS saat bergerak.

INPUT
Tap tile bersebelahan1 langkah + ripple 180ms; tile jauh = tidak ada aksi (bukan teleport)
Joystick (drag)gerak bebas arah, snap ke grid saat lepas; thumb mengikuti jari tanpa re-render tile
Long-press tile / HOLD sprintauto-walk berulang ×2 kecepatan, berhenti saat encounter atau tile blocked
HapticsLightImpact per langkah · MediumImpact saat encounter · SuccessNotification saat catch
FEEDBACK
Cincin putus-putustile yang bisa dituju — selalu terlihat, jadi pemain tidak menebak
Rustlerumput tinggi: animasi goyang + glow → memberi tahu nilai encounter
Meter risikonaik tiap langkah di rumput tinggi, reset setelah encounter → loop terasa hidup
Blockedtile air/batu: shake 120ms + bunyi rendah, tidak diam saja
PERFORMA — PAKAI PRESISI
React.memohanya untuk komponen murni berulang: Tile, PokemonRow, MoveButton, TypeBadge — props primitif + handler stabil
useCallbackhanya untuk handler yang dilempar ke anak ber-memo (onTilePress, onSelectMove, onSwipe). Handler yang tidak masuk props anak → tidak perlu
useMemohanya untuk kerja berat nyata: hasil filter 151 Pokémon (search+type), lookup type-chart 18×18, damage preview. Aritmatika sepele → jangan
✗ janganuseCallback untuk action Zustand (referensinya sudah stabil), useMemo untuk JSX, memo pada komponen yang menerima object/array inline
Pilih selektifuseStore(s => s.risk) + useShallow untuk multi-field — jangan ambil seluruh store
Grid tidak boleh re-renderposisi pemain = Reanimated translateX/Y; 64 tile tetap memo + key stabil (${'$'}{chunkX}:${'$'}{chunkY}:${'$'}{x}:${'$'}{y})
List 151FlatList + getItemLayout + initialNumToRender 12 + windowSize 5 + removeClippedSubviews · sprite via expo-image cachePolicy="memory-disk"
Stylessemua StyleSheet.create di-hoist ke module scope; tidak ada object style inline di dalam row map() — kalau dilanggar, memo jadi sia-sia
Lintreact-hooks/exhaustive-deps = error; tidak boleh di-silence tanpa alasan tertulis
